# 記事データを実データに差し替えてください(重要・公開前に必須)

`articles.json` は今はダミーデータです。**このまま公開すると存在しない記事URLを本物として表示してしまう**ため、必ず実際の朝日新聞デジタルの記事に差し替えてから公開してください。

## やり方

1. https://www.asahi.com/ や https://digital.asahi.com/ で、高校生が「身近な出来事→社会・政治の問題」に気づけそうなテーマの記事を10〜20本探す。
   - テーマ例: 物価高・値上げ、少子化、若者と選挙・投票率、奨学金・教育費、円安、最低賃金、待機児童・子育て支援、年金・社会保障、非正規雇用、気候変動・環境政策 など
2. 各記事について、以下をメモする。
   - 記事の見出し(実際のタイトルをそのまま)
   - 記事のURL(実際のURL)
   - 掲載日
   - 自分の言葉での要約1〜2文(本文をコピペしない。著作権的にNG)
   - キーワード(3〜6個。ユーザーの入力とのマッチングに使う)
   - おおまかなテーマ名
3. `articles.json` の該当エントリをそのメモの内容に置き換える(`SAMPLE-` のidも実際の内容に合わせて変更してOK)。

## なぜAIやWeb検索で自動収集しなかったか

朝日新聞デジタルは会員限定記事が多く、自動的にスクレイピング・要約すると利用規約違反や著作権上の問題になり得ます。また実際に存在するURLかどうかを確実に検証できるのは、実際にページを開いて確認できる人(あなた)だけです。ニュースを扱うサービスとして「出典が実在すること」は最優先事項なので、ここは手作業での収集をおすすめします。10〜20本なら1〜2時間程度で集められるはずです。
